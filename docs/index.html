BOSS 招聘数据爬虫与分析

这是仓库 BossDataAnalysis 的静态项目展示页，用中文说明仓库里能核对到的问题、架构、流程、截图、用法与限制。它不是浏览器演示，也不会在此页启动爬虫或查询数据库。

完整能力依赖本机或服务器上的 Java/Spring Boot、MySQL、ChromeDriver 与（可选）Python 脚本。README 另指向 Bilibili 教程与百度网盘中的「全部代码与连接」。

要解决什么问题

以下三点直接来自 README「项目初衷」，不是本页补充的产品叙事。

1. 给在职程序员看行情

作者写自己也是程序员，希望通过项目帮助同行了解 IT 市场行情，不要被 996 / 007 压榨，并能根据岗位标签衡量自身价值。

2. 给准备入行的同学选型

希望未来想做程序员的人，通过学习项目认识行业、选择要学的技术栈，并清楚学完对应的市场定价，而不是只听培训机构。

3. 给毕设同学做一件具体的事

希望需要写毕业设计的同学，借这个项目体会编程，做「真正有意义」的事情，而不是为毕业而毕业。

README 还写：「这个项目通过 Java-Scala 实现基本的数据挖掘」。本仓库快照里能打开的实现是 Java/Spring Boot 爬虫与分析接口，以及 python/ 下的 NumPy 脚本；未见 Scala / Spark 源码文件。

架构（仅仓库证据）

目录、依赖与类职责如下。未在源码中核实的组件（例如 Spark HashTF 作业、HBase 读写）单独标出，避免写成已实现能力。

Spring Boot 服务

模块目录 SpringBoot_BossSpider_V4_Mysql_5.5/。父 POM 为 Spring Boot 1.4.0.RELEASE，主类 store.eazychina.wtx.ApplicationController。application.properties 中 server.port=9005，Thymeleaf 前缀 classpath:/templates/，模式 LEGACYHTML5。

已声明依赖包括：spring-boot-starter-web、Thymeleaf、NekoHTML、MySQL 驱动、MyBatis、Druid、WebMagic 0.7.3、Selenium 3.x、dom4j / jaxen。POM 另含 hbase-client 与邮件 starter；已检索的 Java 源码未见 HBase 或发信调用。

数据与分析侧

bossdataanalysis.sql 标注为 Navicat 从 MySQL 5.5、库名 bossdataanalysis 导出，日期 2021-12-05。明细表 boss_job_data_deeplearning4beijing 字段与 bossPojo 一致：公司、HR、学历/经验、最低/最高薪、地点、岗位名、标签、实习日薪备用字段。

汇总表包括 boss_addr_money、boss_addr_jobname_money、boss_addr_jobname_money_beijing、boss_china_addr_jobname_money、boss_deeplearning4beijing_jobname_money 等。python/标签挖掘_可视化.py 用 CSV 矩阵求秩并用伪逆估计标签分量。

工作流程

按控制器、爬虫与工具类的调用顺序整理。本页不执行其中任何一步。

  1. 打开 BOSS 直聘职位列表

    源码写死若干 https://www.zhipin.com/job_detail/ 查询，例如「推荐算法」「石家庄javaweb」「算法」「石家庄大数据」，城市参数如 100010000、101010100。

  2. Selenium + WebMagic 抓列表卡片

    SeleniumDownloader 指向本机 ChromeDriver；Site 重试 1 次、休眠 3000ms。页面处理抽取 [class=job-primary]，并向 .page 或 XPath 分页节点追加后续请求。线程数在启动代码里为 1。

  3. HTML 落盘后再结构化

    BossDataUtil.startMakeDataForBossSpider(path) 读目录中的文件。薪资若含「元/天」则记入 otherRed 且 min/max 为 0；否则按 min-maxK 拆成整数。结果用 HashSet 去重。

  4. 写入 MySQL，再按字段查

    /addBossData 调用 BossDataService.addBossData，MyBatis 插入 boss_job_data_deeplearning4beijing。列表页按地点、公司、岗位名、标签 LIKE 过滤，或四条件同时过滤。

  5. 汇总表驱动图表模板

    分析控制器把 avgred、addr、jobName、rank 等放进 JSON，返回例如 /BI/addr_money、/BI/China_jobName_money、/BI/getmoneyforjobnamebybeijing。本快照中没有这些 Thymeleaf/JSP 文件。

  6. Python 对标签矩阵做最小二乘式估计

    标签挖掘_可视化.py 读标签矩阵与薪资向量，比较系数矩阵与增广矩阵的秩，再用伪逆点乘得到每个标签的估计值并写出 CSV。脚本内路径是作者本机 Windows 目录，不在仓库里。

用法（从源码能推出的步骤）

仓库没有逐步安装手册。下面只写配置文件、注解路径和脚本里实际出现的内容。本 GitHub Pages 站点不能代替这些步骤。

  1. 准备 JDK、Maven、MySQL，以及与源码匹配的 ChromeDriver 和 WebMagic config.ini。
  2. 导入 bossdataanalysis.sql（导出头信息：MySQL 5.5，库名 bossdataanalysis）。
  3. 按自己的环境改 application.properties 中的数据源。仓库里有历史主机与账号字段，使用前应整份替换，不要沿用示例机密。
  4. 把爬虫里的驱动路径改成你的机器。源码出现过 Windows G:\爬虫\drive\chromedriver.exe 与 Linux /usr/bin/chromedriver，以及对应的 selenuim_config（源码拼写如此）。
  5. 打包并运行主类 store.eazychina.wtx.ApplicationController。配置默认监听 0.0.0.0:9005。
  6. Python 分析需自行提供脚本里写死的 CSV 路径后运行 python/标签挖掘_可视化.py（或同目录相近脚本）。
  7. README「全部代码与连接」指向百度网盘 https://pan.baidu.com/s/1czBsipp3JmWcAhFxmfkIjQ，提取码 ma2q。本快照缺少页面模板时，网盘可能含其余文件，本页未核验网盘内容。
  8. 配套讲解见 README 视频教程：BV1Kh41167mS。

限制与未证实事项

只写仓库里能直接看到的缺口，以及本页明确不会声称的内容。

这不是可运行演示

GitHub Pages 只托管 docs/ 静态文件。没有 Spring 进程、没有 MySQL、不会调用 ChromeDriver。图表与表格截图不能在本站复现。

本快照缺少前端模板

控制器返回 /jsp/... 与 /BI/...，但仓库内没有对应 HTML/JSP。README 把「全部代码」指向网盘。截图中的 layuiAdmin 壳层也不在本快照里。

选择器绑在旧版职位页 DOM

解析依赖 job-primary、job-name、job-area、tag-item、info-publis 等。站点改版后，现有 XPath/CSS 可能直接失效。

路径与启动参数写死

ChromeDriver、数据目录、部分查询 URL 写在 Java 里。换机器必须改源码或先做配置抽取（仓库未提供统一外置配置）。

依赖年代较早

Spring Boot 1.4、编译插件出现 Java 1.7、WebMagic 0.7.3、Selenium 3。这是 POM 事实，不代表已做现代化升级。

README 中的 HashTF 注意事项

作者写明：按 hashCode 写入 document.length 稀疏矩阵，大数据量才有意义；会丢失变量与 hashCode 的映射，且无法解决哈希冲突。小数据量「没必要用」。

第三方站点与合规

爬虫目标是 BOSS 直聘公开职位列表。是否允许抓取、频率与用途，须自行对照当时法律与网站条款。本页不提供绕过限制的做法。

本页不会给出的数字

不把 SQL 行数、AUTO_INCREMENT、工具类注释里的一次解析循环次数，或截图坐标轴，写成岗位总量、准确率、用户数、生产部署或分析结论。
