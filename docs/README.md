# 静态展示站

本目录是 GitHub Pages 站点源文件，发布地址：

https://unstoppablecurry.github.io/BossDataAnalysis/

这是**静态项目展示**，不是可运行的浏览器演示。招聘数据爬取与分析需要仓库中的 Spring Boot、MySQL 与 ChromeDriver 等后端环境。

由 `.github/workflows/static.yml`（GitHub 官方 static Pages 工作流，产物目录改为 `docs/`）部署。仓库设置里请将 Pages 发布源选为 **GitHub Actions**。
